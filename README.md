# Clonador-de-Pastas-do-Drive
Esta ferramenta foi criada exclusivamente para facilitar e automatizar a cópia de pastas inteiras no Google Drive. Como o Google Drive não possui um botão nativo para duplicar estruturas completas (com subpastas e arquivos aninhados) de forma automática, esta solução em código gera o roteiro perfeito para fazer todo o trabalho pesado em segundos.
